### Fixed

**Audio Router** and **Volume Mixer** no longer list their own private
aggregate devices — a running monitor's plumbing showed up as a routing device
with a trash button, and a running engine's aggregate was offered as an output
to route into.

**Video Downloader** cancel now reaches yt-dlp. **Video Splitter** reports
ffmpeg's actual complaint for a failed clip instead of "ffmpeg failed".

**Clean Drive** never follows a symlink: a link to a directory elsewhere was
sized and reported at the target's size, and a failed remove could descend into
the target.

**Calendar** refreshes every time the panel opens. **Focus Timer** break
steppers re-seed an unstarted break. **Scratchpad** keeps its "Couldn't save"
warning across a note switch. **Color Picker** keeps the exact sampled colour.

### Changed

**System Monitor**, **Volume Mixer**, **Disk Usage Analyzer**, **Clipboard
History**, **Dev Tools**, **QR Studio**, **Duplicate Finder** and
**Uninstaller** each shed per-tick, per-keystroke or per-row work that was
running on the main thread.
